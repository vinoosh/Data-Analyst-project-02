# Project 02 – Transaction Analysis Dashboard

## 📊 Project Overview
An interactive Tableau dashboard for analyzing transaction data based on age group, payment method, merchant, device type, currency, and location.

## 🛠️ Tools Used
- Tableau
- Data Visualization
- Data Analysis

## 📈 Dashboard Features
- Transactions by Age Group
- Transactions by Payment Method
- Merchant-wise Transaction Analysis
- Geographic Transaction Analysis
- Interactive Filters

## 📁 Files
- `Project 02.twbx` – Tableau workbook
- `README.md` – Project documentation

## 🎯 Objective
To analyze transaction patterns and create an interactive dashboard that helps identify trends across customers, payment methods, merchants, and locations.
